# Сайт ИП Драенков А. А. — земляные работы (Молодечно)

Готовый статический сайт: лендинг + страница политики обработки персональных данных.
Без сборки, без CMS, без зависимостей. Открывается двойным кликом по `index.html` и
загружается на любой хостинг как обычные файлы.

## Структура

```
site/
├── index.html            — главная страница (лендинг)
├── politika.html         — политика обработки персональных данных
├── favicon.svg           — иконка сайта
├── robots.txt
├── sitemap.xml
└── assets/
    ├── css/style.css     — все стили (токены в блоке :root)
    ├── js/main.js        — настройки, меню, анимации, форма
    └── img/              — фотографии (hero, drill, trench, landscape, owner)
```

## Что заменить перед публикацией

| Что | Где | Сейчас |
|---|---|---|
| Телефон | поиск `+375293967600` и `+375 (29) 396-76-00` в `index.html`, `politika.html`, `assets/js/main.js` | номер заказчика |
| Домен | теги `canonical`, `og:url`, `og:image`, `sitemap.xml`, `robots.txt` | `https://example.by/` |
| УНП и e-mail | `politika.html`, раздел 1 | `[указать УНП]`, `[указать e-mail]` |
| Фотографии | `assets/img/` (сохранить имена файлов) | демонстрационные снимки |
| Тексты, ковши, буры, география | `index.html` | данные заказчика |

Демонстрационные фотографии — сгенерированные изображения. Перед сдачей клиенту
их нужно заменить на реальные фото работ (те же имена файлов — тогда верстка не
поедет). Рекомендуемый размер: hero 1400×1400, остальные 1200×800, портрет 880×1100.

## Форма заявки

По умолчанию форма валидирует поля и после отправки показывает два действия:
позвонить или открыть WhatsApp с уже подставленным текстом заявки.

Чтобы принимать заявки на e-mail или в CRM, укажите в `assets/js/main.js`:

```js
const CONFIG = {
  phone: '+375293967600',
  whatsapp: '375293967600',
  formEndpoint: 'https://formspree.io/f/ваш-id'  // или Getform, свой скрипт и т.п.
};
```

Заявка уходит POST-запросом в формате JSON: `name`, `phone`, `work`, `message`,
`page`, `date`.

## Публикация

Любой статический хостинг: Netlify Drop (перетащить папку), Vercel, Cloudflare Pages,
GitHub Pages, обычный виртуальный хостинг (залить содержимое `site/` в `public_html`).
HTTPS обязателен — иначе кнопки звонка и WhatsApp работают непредсказуемо.

После публикации замените `example.by` на реальный домен и добавьте сайт в
Яндекс.Вебмастер и Google Search Console.

## SEO, что уже сделано

- семантическая разметка: один `h1`, логичная иерархия `h2/h3`;
- микроразметка Schema.org `LocalBusiness` с телефоном, адресом, географией и услугами;
- Open Graph и Twitter Card для корректных превью в мессенджерах;
- мета-теги с ключевыми запросами по региону;
- `robots.txt` и `sitemap.xml`;
- адаптив от 320 px, доступность: skip-link, aria-атрибуты, фокус-стили, поддержка
  `prefers-reduced-motion`;
- оптимизированные изображения (JPEG, прогрессивные), `lazy` для фото ниже первого экрана.
